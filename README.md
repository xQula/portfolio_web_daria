# SOF — Сайт-портфолио режиссера монтажа Дарьи Евстигнеевой

Сайт-портфолио под брендом **SOF (Sense of Form)** для презентации работ в сфере видеомонтажа, кинопродвижения, рекламы и digital-контента.

---

## 📂 Архитектура и структура проекта

Проект организован по модульному принципу: исходный код разбит на независимые CSS и JS модули и изолирован в папке `src/`.

### Структура каталогов
```
portfolio_web_daria/
├── index.html                 # Точка входа (мета-редирект на src/html/index.html)
├── package.json               # Зависимости и скрипты запуска сервера
├── README.md                  # Главная документация проекта
├── projects/                  # База данных проектов в формате JSON
│   ├── README.md              # Документация по наполнению проектов
│   ├── index.json             # Индексный файл со списком видеороликов
│   ├── video/                 # Папка с видео-проектами (velvet_light.json и др.)
│   └── art/                   # Папка с шаблонами арт-карточек (can_be_different.json и др.)
│       └── index.json         # Индексный файл со списком арт-карточек
├── res/                       # Ресурсы (шрифты, изображения)
└── src/                       # Исходный код модулей
    ├── html/
    │   └── index.html         # Основная HTML-разметка
    ├── css/                   # Модули стилей (Vanilla CSS)
    │   ├── main.css           # Главный файл стилей (импортирует остальные)
    │   ├── variables.css      # Переменные темы оформления и шрифты
    │   ├── base.css           # Базовые стили и сбросы
    │   ├── header.css         # Шапка и переключатель тем
    │   ├── hero.css           # Первый экран (Hero)
    │   ├── portfolio.css      # Сетка портфолио и карточки
    │   ├── modals.css         # Лайтбокс и контакты
    │   └── footer.css         # Подвал сайта
    └── js/                    # Модули логики (ES6 Modules)
        ├── main.js            # Точка входа (инициализация приложения)
        ├── config.js          # Конфигурационные константы
        ├── api.js             # Загрузка JSON, авто-эмбед и авто-превью YouTube
        ├── theme.js           # Переключение тем с анимацией радиального раскрытия
        ├── lightbox.js        # Управление всплывающим видеоплеером
        ├── contact.js         # Управление модальным окном контактов
        └── grid.js            # Логика построения сетки и фильтрации
```

## 🛠️ Особенности реализации

### 1. Модульный JavaScript (ES6 Modules)
Все скрипты используют нативный стандарт ES6 модулей. Скрипт подключается в HTML как:
```html
<script type="module" src="../js/main.js"></script>
```
Импорты осуществляются нативно браузером, что исключает необходимость использования тяжелых сборщиков (Webpack/Vite) на этапе разработки.

### 2. Модульный CSS
Стили разделены по файлам компонентов и подключаются в главном файле `main.css` с помощью `@import`:
```css
@import "variables.css";
@import "base.css";
/* ... */
```

### 3. Автоматизация медиа-контента
* **Авто-превью YouTube:** Для видео с YouTube не требуется вручную прописывать ссылки на картинки-обложки. Поле `"preview"` в JSON можно оставить пустым, и код сгенерирует URL обложки автоматически с резервным фолбеком качества в случае ошибки 404.
* **Авто-эмбед:** Любые вставленные YouTube и RuTube ссылки автоматически преобразуются во встроенный (`embed`) формат плеера.

## 🚀 Запуск проекта локально

Для запуска локального сервера разработки выполните команду:

```bash
npm run dev
```

После этого сайт будет доступен по адресу: **`http://127.0.0.1:8080/`** (с автоматическим обновлением страницы при изменении кода).
