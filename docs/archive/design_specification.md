# Спецификация дизайна и верстки: Портфолио SOF (Sence of Form)

Этот документ содержит все правила верстки, цветовые схемы, правила типографики и структуру проекта. Используется как техническое задание (ТЗ) для разработки. Он полностью соответствует макету референса.

---

## 🎨 Дизайн-система и Цвета

Сайт поддерживает две темы: **Светлую (основная, по умолчанию)** и **Темную (дополнительная)**, с переключателем.

### Цветовые Токены (CSS Variables)

```css
/* Светлая тема (По умолчанию, как на референсе) */
:root {
  --color-bg-primary: #E0DBC6;       /* Warm Sand - Основной бежевый фон */
  --color-bg-secondary: #EFEFEF;     /* Off-White - Фон карточек, панелей */
  --color-bg-contrast: #122024;      /* Slate Dark - Контрастный темный */
  --color-text-primary: #122024;     /* Slate Dark - Основной текст */
  --color-text-secondary: #6B7280;   /* Серый - Второстепенный текст */
  --color-text-light: #EFEFEF;       /* Off-White - Текст на темном фоне */
  --color-accent: #CCFF00;           /* Lime Accent - Лаймовая кнопка / Ховер */
  --color-border: rgba(18, 32, 36, 0.15); /* Тонкая граница для элементов */
  
  --font-sans: 'Inter', 'Outfit', sans-serif;
  --font-serif: 'Bodoni Moda', 'Playfair Display', serif;
  --font-gothic: 'UnifrakturMaguntia', serif;
}

/* Темная тема */
[data-theme="dark"] {
  --color-bg-primary: #122024;       /* Slate Dark - Основной темный фон */
  --color-bg-secondary: #1C2E33;     /* Чуть более светлый сланец для карточек */
  --color-bg-contrast: #EFEFEF;      /* Off-White - Контрастный светлый */
  --color-text-primary: #EFEFEF;     /* Off-White - Основной текст */
  --color-text-secondary: #9CA3AF;   /* Светло-серый - Второстепенный текст */
  --color-text-light: #122024;       /* Slate Dark - Текст на светлом фоне */
  --color-accent: #CCFF00;           /* Lime Accent - Лаймовая кнопка / Ховер */
  --color-border: rgba(239, 239, 239, 0.15);
}
```

## ✍️ Типографика и Шрифты

Мы сочетаем три разных характера шрифтов для создания премиального журнального вида:
1.  **Основной текст и интерфейс (Sans-Serif):** `Inter` или `Outfit`. Минималистичный, легко читается.
2.  **Заголовки проектов и акценты (Serif):** `Bodoni Moda` или `Playfair Display`. Высококонтрастный шрифт с засечками для создания люксового стиля (имитация шрифта *Mak* из брендбука).
3.  **Эмоциональные акценты (Gothic / Mono):** `UnifrakturMaguntia`. Используется для декоративных надписей и лозунгов.

## 📐 Верстка и Сетка (Точно по референсу)

### 1. Хедер (Header)
*   **Фон:** Чистый белый цвет с прозрачностью 90% (`rgba(255, 255, 255, 0.9)`) в светлой теме, и вторичный темный цвет карточек `rgba(28, 46, 51, 0.9)` (цвет карточек `#1C2E33` с прозрачностью) в темной теме с эффектом матового стекла (backdrop-filter) для гармоничного отделения хедера.
*   **Слева:** Логотип `SOF` + `Sence of Form` (где `S` — Serif шрифт, `O` — геометрический круг с лаймовой обводкой, `F` — стилизованная гранж-буква).
*   **Справа:**
    *   Меню навигации: `HOME`, `PORTFOLIO`, `CONTACT`. Кнопки остаются темными по умолчанию (белыми в темной теме), а при наведении плавно появляется капсула цвета акцента (лаймовая подложка) с темным текстом для высокой контрастности.
    *   Кнопка переключателя темы (иконка Солнца/Луны).
    *   Кнопка `START A PROJECT` (зелено-лаймовый фон, скругленная капсула/pill, черный жирный шрифт).

### 2. Главный экран (Hero Section)
*   Двухколоночный макет на десктопе:
    *   **Левая колонка (60% ширины):** Крупный заголовок `"ELEVATING STORIES THROUGH FORM & MOVEMENT"` (шрифт Sans-serif, bold, uppercase) и подзаголовок `"High-fashion video production brand."`.
    *   **Правая колонка (40% ширины):** Выделенный главный проект (Featured Video). Изображение-превью с центральной круглой лаймовой кнопкой воспроизведения. Под видео подпись: `"THE ESSENCE | AW24 | CAMPAIGN"`.

### 3. Сетка портфолио (Portfolio Grid)
Сетка строится на базе 3 колонок (`grid-template-columns: repeat(3, 1fr)`) с зазором `gap: 2rem`.

*   **Карточки проектов:**
    *   Каждая карточка содержит обложку (видео-превью) с соотношением сторон `16:9` (или `9:16` для вертикальных Shorts, занимающих 1 колонку по ширине и имеющих большую высоту).
    *   В центре обложки — круглая лаймовая кнопка `Play` с черным треугольником.
    *   В правом нижнем углу обложки — темная полупрозрачная плашка с хронометражем (например, `2:15`).
    *   **Информационный блок под обложкой:**
        *   Верхняя строка: Название проекта слева (`VELVET & LIGHT`), хронометраж справа (`2:15`). Шрифт Sans-serif, bold.
        *   Нижняя строка: Категория и детали (`Fashion film | NINA RICCI`) шрифтом поменьше и серым цветом (`--color-text-secondary`).
*   **Арт-вставки (Шахматный эффект):**
    *   Некоторые карточки в сетке могут содержать концептуальные фото или текстовые лозунги бренда (например, `"CAN BE DIFFERENT"` с использованием шрифта Serif/Gothic), разбавляя видео-контент.

### 4. Кнопка "Показать еще" (Show More)
*   Под сеткой портфолио располагается центрированная кнопка `"SHOW MORE"`, выполненная в виде лаймовой капсулы.

### 5. Подвал (Footer)
*   **Фон:** Соответствует цвету карточек текущей темы (`--color-bg-secondary`), что убирает ошибку с перепутанными темами (теперь подвал светлый в светлой теме и темный в темной).
*   **Слева:** Логотип `SOF Sence of Form`.
*   **По центру:** Дублирующее меню: `HOME`, `PORTFOLIO`, `CONTACT`. Ссылки яркие, при наведении на них появляется лаймовая капсула-ховер (как в хедере).
*   **Справа:** Векторные круглые иконки социальных сетей (Telegram, VK, YouTube, RuTube, Email) с контуром толщиной 2px (соответствует кнопке смены темы) основного цвета темы и лаймовым ховером, а также копирайт `© Sence of Form`.

## ⚙️ Функциональные Спецификации

1.  **Кастомный Lightbox:** При клике на карточку открывается модальное окно с размытием фона (`backdrop-filter: blur(8px)`), где воспроизводится плеер YouTube или RuTube. Размеры плеера адаптируются: `16:9` для горизонтальных видео и узкий по центру `9:16` для вертикальных.
2.  **Переключение тем:** Плавное изменение темы с помощью современных технологий:
    *   **Celestial Toggle Morph:** Кнопка переключателя анимирует иконку: луна вращается и улетает в сторону, а солнце вращается и появляется из центра (и наоборот). Используются высокоточные векторные SVG с `shape-rendering="geometricPrecision"`, исключающие пикселизацию.
    *   **Theme Circular Ripple Reveal:** Переход тем осуществляется через современный API `document.startViewTransition`. При клике по экрану запускается круговая анимация раскрытия (ripple mask clip-path), расходящаяся от точки клика на весь экран, плавно перекрывая старый дизайн новым.
3.  **Фильтрация по категориям:** В шапку портфолио добавлен блок категорий (Все, Горизонтальные, Вертикальные), которые скрывают/показывают карточки с анимацией.
