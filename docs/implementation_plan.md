# План реализации (Implementation Plan): Портфолио SOF (Sence of Form)

Этот документ описывает технические этапы разработки сайта-портфолио для режиссера монтажа на основе фирменного стиля брендбука SOF и референсного скриншота.

---

## 📂 Структура проекта

Сайт разрабатывается как легковесное статическое приложение (Single Page Application) без необходимости сборки:
```
portfolio_web_daria/
├── docs/
│   ├── design_specification.md    # Спецификация дизайна
│   └── implementation_plan.md     # План реализации (этот файл)
├── index.html                     # Главная страница (структура)
├── styles.css                     # Таблица стилей (адаптивный Grid, темы)
├── app.js                         # Логика (фильтрация, плеер, смена тем)
└── example/
    └── brandbook_SOF.pdf          # Исходный брендбук
```

---

## 🛠️ Шаги разработки

### Шаг 1: Разметка HTML (`index.html`)
1.  **Настройка тега `<head>`:** Подключение шрифтов Google Fonts (`Inter`, `Bodoni Moda`, `UnifrakturMaguntia`) и подключение `styles.css`.
2.  **Шапка (Header):** Ссылка-логотип с буквами S, O, F в различных шрифтах, блок меню навигации, иконка-переключатель темы (SVG солнца/луны) и скругленная кнопка капсула `START A PROJECT`.
3.  **Первый экран (Hero):** 2-колоночный Flex/Grid контейнер. Слева — крупный текстовый слоган, справа — карточка Featured Video с центральной кнопкой Play.
4.  **Категории портфолио:** Панель с кнопками-фильтрами: "Все проекты", "Горизонтальные", "Вертикальные (Shorts/Reels)", "Реклама", "Клипы".
5.  **Сетка проектов (`#project-grid`):** Базовый контейнер для видеокарточек, которые будут генерироваться динамически через JS.
6.  **Модальное окно (Lightbox):** Блок с `#video-lightbox`, содержащий контейнер для `iframe` (соотношение сторон адаптивное 16:9 / 9:16) и блок с метаданными (название, роль, софт).
7.  **Подвал (Footer):** Логотип, ссылки меню, иконки соцсетей и копирайт.

### Шаг 2: Стилизация CSS (`styles.css`)
1.  **CSS-переменные:** Регистрация переменных цветов для светлой темы (по умолчанию) и темного режима `[data-theme="dark"]`.
2.  **Шрифтовые правила:** Настройка `font-family` для различных тегов и классов.
3.  **Сеточные макеты:**
    *   `display: grid` для сетки портфолио с 3 колонками на десктопе (`repeat(3, 1fr)`) и перестроением в 1-2 колонки на планшетах/мобильных устройствах.
    *   Пропорции: `aspect-ratio: 16/9` для горизонтальных карточек и `aspect-ratio: 9/16` для вертикальных.
4.  **Стили интерактивных кнопок и карточек:**
    *   Отрисовка круглого лаймового плеера по центру обложек.
    *   Хронометраж в углу с полупрозрачным фоном.
    *   Ховер-эффекты: плавный сдвиг вверх, появление лаймового свечения (`box-shadow`), увеличение кнопки `Play`.
5.  **Модальное окно:** Абсолютное позиционирование, размытие заднего плана `backdrop-filter: blur(8px)`.
6.  **Транзиции:** Добавление `transition: background-color 0.4s ease, color 0.4s ease, border-color 0.4s ease` для плавного переключения темы.

### Шаг 3: Программирование логики (`app.js`)
1.  **База данных проектов:** Создание массива объектов:
    ```javascript
    const projects = [
      {
        id: 1,
        title: "VELVET & LIGHT",
        duration: "2:15",
        category: "horizontal",
        subCategory: "Fashion film",
        client: "NINA RICCI",
        videoUrl: "https://www.youtube.com/embed/dQw4w9WgXcQ", // Демо-ссылка
        aspect: "horizontal",
        preview: "assets/preview1.jpg"
      },
      // ... другие проекты (включая вертикальные с aspect: "vertical")
    ];
    ```
2.  **Генерация карточек:** Функция, которая рендерит разметку карточек в `#project-grid` с учетом структуры (заголовок слева, длительность справа, описание снизу).
3.  **Система фильтрации:** Добавление слушателей событий на кнопки категорий. При клике происходит фильтрация массива и плавный перезапуск отрисовки карточек (с классом анимации `fade-in`).
4.  **Управление Lightbox:**
    *   При клике на карточку считывается `videoUrl` и создается тег `iframe`.
    *   Модальное окно получает класс активности, блокируется скролл страницы.
    *   Подставляется правильный класс пропорций (`16:9` или `9:16`) в зависимости от типа видео.
    *   При клике на крестик или мимо окна плеер очищается (`iframe.src = ''`), модальное окно скрывается.
5.  **Переключение тем:**
    *   Функция, меняющая атрибут `data-theme` у `document.documentElement` между `light` и `dark`.
    *   Сохранение состояния темы в `localStorage.setItem('theme', ...)` и проверка при загрузке страницы.

## 🔍 План проверки (Verification)

1.  **Визуальная сверка с референсом:** Открыть страницу в браузере и сравнить взаимное расположение блоков, размеры шрифтов, отступы и цвета со скриншотом.
2.  **Тестирование адаптивности:** Сузить экран до мобильного размера, проверить, чтобы сетка перестраивалась в одну колонку, а меню пряталось/удобно сворачивалось.
3.  **Тестирование плееров (YouTube / RuTube):** Убедиться, что ссылки воспроизводятся корректно, нет ошибок в консоли, а при закрытии окна звук видео прекращается.
4.  **Тестирование смены тем:** Проверить плавность перехода цветов и сохранение темы после перезагрузки страницы.
