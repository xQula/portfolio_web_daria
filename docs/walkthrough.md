# Отчет о выполнении доработок доступности и контрастности (Walkthrough)

В рамках этого этапа мы завершили внедрение продвинутого управления фокусом и привели сайт в соответствие со стандартами доступности WCAG AA по контрастности текста.

---

## 🛠️ Что было сделано

### 1. Соответствие WCAG AA по контрастности текста
* **Файл:** [variables.css](file:///d:/repo/source/portfolio_web_daria/src/css/variables.css)
* **Изменение:** Значение переменной `--color-text-secondary` в светлой теме было обновлено с `#6B7280` на более темный и читаемый оттенок серого `#4B5563`.
* **Результат:** На теплом бежевом фоне страницы `#E0DBC6` коэффициент контрастности второстепенного текста (описания проектов, метаданные) вырос с недостаточных `3.4:1` до **`5.1:1`**, что полностью удовлетворяет строгому стандарту **WCAG AA** для мелких шрифтов (минимум `4.5:1`).

### 2. Реализация ловушки фокуса (Focus Trap) в контактах
* **Файл:** [contact.js](file:///d:/repo/source/portfolio_web_daria/src/js/contact.js)
* **Изменение:** Добавлен слушатель клавиатуры `keydown` на контейнер `#contact-modal`. При нажатии клавиши `Tab` или сочетания `Shift + Tab` фокус циклически удерживается внутри элементов модального окна.
* **Поведение:** Фокус ходит исключительно по цепочке: `Кнопка Закрытия` ⇄ `Telegram-ссылка` ⇄ `VK-ссылка` ⇄ `Email-ссылка` ⇄ `Кнопка Закрытия`. Выйти за пределы окна на задний фон страницы с помощью клавиатуры невозможно, пока окно не будет закрыто (по клику, крестику или клавише `Escape`).

### 3. Реализация ловушки фокуса (Focus Trap) в видео-лайтбоксе
* **Файл:** [lightbox.js](file:///d:/repo/source/portfolio_web_daria/src/js/lightbox.js)
* **Изменение:** Добавлен слушатель клавиатуры `keydown` на контейнер `#video-lightbox` для циклического удержания фокуса.
* **Поведение:** Учитывая динамическую вставку встроенного `iframe` YouTube/RuTube, фокус переключается между кнопкой закрытия и элементами управления видеоплеера внутри фрейма, предотвращая утечку фокуса на элементы основной страницы.
