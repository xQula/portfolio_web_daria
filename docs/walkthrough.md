# Отчет о выполнении архитектурной миграции и рефакторинга стилей (Walkthrough)

В рамках задачи мы перевели проект на современную архитектуру, подключив сборщик **Vite**, избавившись от лишнего редиректа входа и оптимизировав загрузку ресурсов. Во втором и третьем этапах была проведена глобальная переработка доступности (a11y) и архитектурная чистка CSS со сбором медиа-запросов в соответствующие файлы.

---

## 🛠️ Что было сделано

### 1. Архитектурный рефакторинг CSS (CSS Maintainability)
Адаптивные стили для всего сайта были распределены из одного файла `modals.css` в соответствующие файлы компонентов для поддержания модульности кода:
*   **Base (`base.css`):** Перенесен глобальный адаптивный размер шрифта `html { font-size: 14px; }` для экранов `< 768px`.
*   **Header (`header.css`):** Перенесено правило скрытия навигационного меню `.main-nav { display: none; }` для мобильных устройств.
*   **Hero (`hero.css`):** Сюда перенесены медиа-запросы адаптивности первого экрана `.hero-container`, `.hero-cta` и `.hero-bio` для разрешения `@media (max-width: 1024px)`.
*   **Portfolio Grid (`portfolio.css`):** Сюда перенесены все адаптивные правила для сетки проектов и карточек, включая сброс колонок и строк, а также пропорции превью на мобильных устройствах.
*   **Footer (`footer.css`):** Сюда перенесены двухколоночные медиа-запросы для подвала сайта на ширине `< 1024px`.
*   **Modals (`modals.css`):** Очищен от всех внешних правил. Теперь файл отвечает исключительно за позиционирование и стилизацию всплывающих окон `.lightbox` и `.contact-modal`.

### 2. Глобальная доступность для клавиатуры (Accessibility / a11y)
*   В [src/css/base.css](file:///d:/repo/source/portfolio_web_daria/src/css/base.css) добавлено глобальное правило подсветки фокуса:
    ```css
    a:focus-visible,
    button:focus-visible,
    [tabindex="0"]:focus-visible {
      outline: 3px solid var(--color-accent);
      outline-offset: 4px;
    }
    ```
    Это делает перемещение клавишей `Tab` видимым на всех ссылках меню, кнопках и переключателе тем на бежевом/темном фонах.
*   Динамически создаваемым карточкам проектов в [src/js/grid.js](file:///d:/repo/source/portfolio_web_daria/src/js/grid.js) добавлен атрибут `tabindex="0"`.
*   Добавлены обработчики событий клавиатуры: видео-лайтбокс открывается по нажатию клавиш `Enter` и `Space`.
*   В стили добавлен псевдокласс `.project-card:focus-visible` для анимации карточки вверх при фокусе с клавиатуры.

### 3. SEO-оптимизация и Favicon
*   В `<head>` добавлен легковесный SVG-favicon 🎬 на базе встроенного кода.
*   Интегрированы мета-теги **Open Graph** и **Twitter Cards** для красивого превью ссылок в мессенджерах.
*   Добавлена валидная JSON-LD разметка **Schema.org/Person** с описанием рода деятельности и социальных ссылок.
