# Инструкция по управлению проектами портфолио

Данный раздел содержит инструкции о том, как добавлять, изменять и удалять проекты на сайте-портфолио SOF.

## 📂 Структура файлов

Все проекты хранятся в папке `projects/` в формате JSON:
* `projects/index.json` — индексный файл, содержащий список всех активных проектов и определяющий порядок их вывода.
* `projects/*.json` — отдельные файлы с детальным описанием каждого проекта.

---

## 🎨 Руководство по заполнению полей

Каждый файл проекта (например, `projects/velvet_light.json`) имеет следующую структуру:

```json
{
  "id": 1,
  "type": "video",
  "title": "VELVET & LIGHT",
  "duration": "2:15",
  "category": "commercial",
  "subCategory": "Fashion film",
  "client": "NINA RICCI",
  "videoUrl": "https://www.youtube.com/embed/n9xhJrPXy4g", 
  "aspect": "horizontal",
  "preview": "https://images.unsplash.com/photo-1515886657613-9f3515b0c78f?q=80&w=600&auto=format&fit=crop",
  "soft": "Adobe Premiere Pro · DaVinci Resolve",
  "desc": "Описание ролика..."
}
```

### Спецификация полей:
1. **`id`** *(число или строка)*: Уникальный идентификатор проекта (например, `1`, `2` или `"showreel"`).
2. **`type`** *(строка)*: Тип элемента.
   * `"video"` — для видео-карточки.
   * `"art"` — для текстового шахматного блока (например, "CAN BE DIFFERENT").
3. **`title`** *(строка)*: Название проекта (отображается жирным шрифтом).
4. **`duration`** *(строка)*: Длительность видео в формате `М:СС` (например, `"2:15"` или `"0:45"`). Отображается на превью.
5. **`category`** *(строка)*: Категория фильтра на сайте:
   * `"trailers"` — Кинопродвижение (трейлеры/тизеры)
   * `"commercial"` — Реклама
   * `"music"` — Клипы
   * `"vertical"` — Shorts / Reels (вертикальный контент)
6. **`subCategory`** *(строка)*: Подкатегория/жанр (например, `"Dance film"` или `"Instagram Reels / TikTok"`).
7. **`client`** *(строка)*: Заказчик / бренд (например, `"NINA RICCI"`).
8. **`videoUrl`** *(строка)*: Ссылка для встраивания плеера (embed).
   * *YouTube*: `https://www.youtube.com/embed/КОД_ВИДЕО`
   * *RuTube*: `https://rutube.ru/play/embed/КОД_ВИДЕО`
9. **`aspect`** *(строка)*: Пропорции элемента.
   * *Для видео*: `"horizontal"` — горизонтальное (16:9), `"vertical"` — вертикальное (9:16).
   * *Для арт-вставок (type: "art")*: `"horizontal"` — занимает 2 колонки в ширину, `"vertical"` — занимает 1 колонку в ширину и 2 строки в высоту. По умолчанию используется `"horizontal"`.
10. **`preview`** *(строка)*: Ссылка на обложку видео (картинку-превью).
11. **`soft`** *(строка)*: Программы, в которых монтировался ролик. Перечисляются через точку ` · `.
12. **`desc`** *(строка)*: Подробное описание процесса работы и монтажа (отображается в плеере).
13. **`featured`** *(булево, опционально)*:
    * `true` — выводит данный проект на главный экран (Hero) в качестве основного видео.
    * `false` или отсутствует — не выводит.
14. **`hideFromGrid`** *(булево, опционально)*:
    * `true` — скрывает проект из нижнего общего списка работ (полезно для шоурилов, которые должны быть только на главном экране).
    * `false` или отсутствует — отображает проект в сетке.

## ⚡ Как добавить новый проект:
1. Создайте в папке `projects/` новый файл с расширением `.json` (например, `projects/my_awesome_video.json`).
2. Скопируйте туда структуру из любого другого проекта и заполните свои данные.
3. Откройте файл `projects/index.json` и добавьте имя вашего файла в массив (в то место, где он должен находиться по порядку):
   ```json
   [
     "showreel_2026.json",
     "my_awesome_video.json",
     ...
   ]
   ```
4. Сохраните изменения. Проект сразу же появится на сайте!
